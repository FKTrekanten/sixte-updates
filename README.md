# Sixte — update mirror

Build artifacts only: the installable `pkg_sixte-*.zip`, the Joomla update-site `update.xml` and the cumulative Joomla `changelog.xml` for each Sixte release, published automatically by the private source repository's release workflow. No source code lives here.

Joomla finds updates through the update site in the package manifest:
`https://github.com/FKTrekanten/sixte-updates/releases/latest/download/update.xml`
